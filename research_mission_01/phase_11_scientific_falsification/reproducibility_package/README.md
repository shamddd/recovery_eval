# recovery_eval: Protocol 2.0 Reproducibility Package

This package contains the complete, self-contained empirical dataset and standalone evaluation scripts to independently reproduce all statistical tables and figures from the `recovery_eval` publication.

**No GPU or CUDA runtime is required.** The statistical reproduction script executes entirely on standard CPU in < 1 second.

---

## 1. Package Contents

- `10_COMPLETE_QWEN_PROTOCOL2_ROLLOUTS.jsonl`: The complete 400-rollout dataset generated by official Qwen2.5-Math-1.5B Base and Instruct models on RunPod (NVIDIA RTX 4090).
- `10_COMPLETE_QWEN_PROTOCOL2_ROLLOUTS.jsonl.sha256`: Cryptographic checksum file.
- `BALANCED_PROMPT_REGISTRY.json`: The frozen prompt registry defining the 20 synthetic arithmetic problems and state-matched prefixes.
- `model_manifest.json`: Pinned Hugging Face Hub revisions for the Base (`4a83ca6`) and Instruct (`aafeb0f`) checkpoints.
- `reproduce_protocol2_statistics.py`: Standalone Python script that verifies dataset checksums, scores rollouts across heuristic and structural regimes, and calculates cluster-robust standard errors.
- `requirements.txt`: Minimal dependencies (`numpy`, `scipy`).
- `LICENSE_AND_PROVENANCE.md`: Licensing and dataset provenance disclosure.
- `KNOWN_LIMITATIONS.md`: Experimental scope and methodological boundaries.

---

## 2. Quick Reproduction (CPU Only)

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Verify SHA-256 Checksum
```bash
shasum -a 256 -c 10_COMPLETE_QWEN_PROTOCOL2_ROLLOUTS.jsonl.sha256
```
Expected output:
```
10_COMPLETE_QWEN_PROTOCOL2_ROLLOUTS.jsonl: OK
```

### Step 3: Run Reproduction Script
```bash
python3 reproduce_protocol2_statistics.py
```

Expected output:
- Heuristic MathVerifier: Base Control: 0.9700, Base Recovery: 0.0000, Instruct Control: 1.0000, Instruct Recovery: 0.0000, $D = -0.0300$, $SE_{\text{cluster}} = 0.0164$, $p = 0.0828$.
- Structural / Semantic Verifier: Base Control: 1.0000, Base Recovery: 0.0000, Instruct Control: 1.0000, Instruct Recovery: 0.0000, $D = 0.0000$, $SE_{\text{cluster}} = 0.0000$, $p = 1.0000$.
